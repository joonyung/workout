# Codex 코칭 프로토콜

## 역할 분리

Workout OS는 실행기이자 기록기다. Codex는 코치 역할을 맡아 저장된 데이터와
제약을 읽고 당일 프로그램과 주기별 조정안을 파일로 만든다.

- PWA: 오늘 프로그램 표시, 세트별 중량·반복·RPE·완료 기록, 타이머,
  프로필·체육관·인바디 입력
- Codex: 운동 선택, 볼륨·강도·휴식 처방, 대체 운동, 주간·월간 리뷰
- 파일 데이터: 두 역할이 공유하는 단일 기준

브라우저 저장소는 운동 중 즉시 반응과 오프라인 대비용이다. 로컬 서버가
연결되어 있으면 같은 기록을 runtime `data/workouts`에도 저장한다. Codex는 다음
프로그램을 만들 때 브라우저가 아니라 이 파일을 읽는다. 생성 절차는
`AGENTS.md`의 Daily Program Generation을 따른다.

## 근거 기반 기본값

2026년 ACSM 업데이트는 복잡한 기법보다 꾸준한 수행을 우선하고, 주요
근육군을 주 2회 이상 훈련하며, 근비대 목표에는 근육군당 주당 약 10세트
수준의 높은 볼륨을 출발점으로 제시한다. 머신과 프리웨이트의 우열이나
매 세트 실패 지점까지 가는 것은 평균적인 건강한 성인에게 필수 조건으로
보지 않는다.

- 주요 근육군을 주 2회 이상 자극한다.
- 근육군별 주당 직접 세트는 약 8-12세트를 목표로 한다. 측면 삼각근·이두·
  삼두·햄스트링 같은 작은 근육도 복합 운동의 간접 자극으로 대신하지 않고
  직접 세트를 둔다.
- 대부분의 작업 세트는 RPE 7-9, 즉 대략 1-3 RIR 범위로 둔다. 실패 지점은
  필수가 아니며, 안전한 머신 고립 운동의 마지막 세트에서 가끔 사용해 실제
  여력을 확인하는 정도로 쓴다.
- InBody는 수분과 측정 조건의 영향이 크므로 같은 조건(아침 공복, 운동 전)에서
  잰 여러 측정의 방향성만 본다. 일일 중량 처방의 입력값으로 쓰지 않는다.
- 워밍업 세트는 기록해도 작업 세트 볼륨, 수행률, e1RM, 증량 판단에서 제외한다.

## 종목별 증량 규칙

증량은 종목마다 매 세션 자동으로 판단한다. 리뷰를 기다리거나 한 주에 한
종목씩만 올리지 않는다. 같은 세션에서 여러 종목이 동시에 올라가도 된다.
종목별 증량은 프로그램 구조 변경으로 보지 않는다.

1. 기준은 같은 운동 id·같은 기기의 마지막 실제 완료 기록의 작업 세트다.
   계획에만 있던 중량이나 건너뛴 세션은 기준이 아니다. 계획했지만 수행하지
   못한 증량은 다음 같은 종목 세션에 그대로 이월한다.
2. 마지막 기록에 따라 다음 처방을 정한다.

   | 마지막 기록 | 다음 처방 |
   |---|---|
   | 모든 작업 세트가 반복 범위 상단, RPE가 목표 이하, 통증 없음 | 증량 |
   | 범위 안이지만 상단 미달 | 중량 유지, 반복 추가 |
   | 범위 안이지만 RPE가 목표보다 1 이상 높음 | 중량 유지 |
   | 2세트 이상 하단 미달 또는 RPE 9.5 이상 | 2.5-7.5% 감량 또는 1세트 감소 |

3. 증량 폭은 그 기기의 최소 단위다. 최소 단위가 현재 중량의 약 7.5%보다
   크면(예: 22.5kg → 25kg) 중량 대신 반복 범위를 2-3회 위로 옮겨
   (예: 10-12회 → 12-15회) 반복으로 먼저 진행한다. 새 상단을 모든 세트에서
   채우면 증량하면서 원래 범위로 돌아간다.
4. 같은 중량에서 반복수가 3회 연속 늘지 않으면 정체로 보고, 그 종목의 반복
   범위나 변형 중 하나를 바꾼다.
5. readiness가 tired이거나, 해당 부위에 통증·경고감이 있거나, 워밍업이 평소보다
   확실히 무거우면 그날은 직전 중량을 유지하고 다음 세션에 다시 판단한다.
6. 새 운동이나 새 기기는 첫 세션에 중량을 환산하지 않고, 준비 세트 후 목표
   반복을 RPE 7-8로 하는 중량으로 기준선을 만든다. 다른 기기의 표시 중량은
   같은 운동 이름이어도 별도 기준선이다.
7. 수행률(계획 대비 완료 세트)이 85% 미만이면 증량이나 볼륨 추가보다 세션
   길이와 운동 수를 먼저 줄인다.

## 프로그램 구조 변경

구조는 주당 세트 수, 빈도, 종목 구성, 교대 방식을 말한다.

- 구조는 4-6주 블록 단위로 유지하고 매 세션·매주 바꾸지 않는다.
- 구조 변경은 블록 경계(월간 리뷰)에서 하거나, 수행률 85% 미만·여러 종목
  동시 정체·통증·일정이나 체육관 변화·사용자 요청이 있을 때 한다.
- 필요한 변경은 한 번에 묶어 적용해도 된다. 변경 이유와 다음 확인 시점은
  runtime `data/reviews/`에 남긴다.
- 2-4주 연속 성과 저하와 피로 신호가 함께 있으면 1주 동안 세트 수를 약
  30-50% 줄이는 디로드를 검토한다.

## 컨디션과 통증

- 회복과 통증은 기록(readiness, 세션 RPE, 메모, 누락 세트, 프로필의 통증
  메모)으로 판단한다. 계획을 만들 때마다 통증·피로·장소를 사용자에게 다시
  확인받지 않는다. 당일 변동은 계획 안의 RPE 상한, 감량 기준, 통증 시 중단
  큐로 처리한다.
- 기록에 경고 신호(통증 메모, tired 연속, 갑작스러운 누락)가 있거나, 통증 이력
  부위에 새 고부하 복합 운동을 도입할 때만 처방 전에 사용자에게 확인한다.
- 통증, 어지럼증, 흉통 등 의학적 평가가 필요한 신호는 프로그램 자동 조정
  범위를 벗어난다.

## 현재 블록 구성

2026-10-05 사용자 합의, 2026-10-16 갱신(블록 시작).

- 격일 A/B 교대.
  - 벤치일: 바벨 벤치, 수직 당기기, 레그 익스텐션, 레그 컬, 리어델트,
    레터럴 레이즈, 이두.
  - 스쿼트일: 바벨 스쿼트, 머신 체스트프레스, 수평 당기기, 숄더프레스,
    힙쓰러스트, 레터럴 레이즈, 삼두.
- 랫풀다운은 케이블과 레버형 머신을, 로우는 케이블과 가슴 지지 머신을 각각
  번갈아 한다. 다음 변형은 그 패턴의 마지막 실제 완료 기록으로 정한다. 네
  변형은 별도 운동 id와 기준선을 쓴다.
- 마무리 좌식 사이클 10-15분, RPE 3-4. 시간이 부족하면 가장 먼저 줄인다.
- 세션 목표는 70분이다. 기본은 한 운동씩 수행한다. 슈퍼세트는 근비대
  효과를 더하지 않고 시간만 줄이므로, 시간이 부족한 날에만 서로 겹치지 않는
  부위의 보조 종목(예: 레그 익스텐션과 레그 컬)을 묶는 선택지로 둔다.

## 장소와 장비

- `available` 또는 `limited` 장비만 필수 전제로 쓴다. `unknown`이면 대체 운동을
  함께 넣는다.
- 운동 장소가 바뀌면 runtime `data/gyms/current.json`을 해당 장소 프로필로
  전환한다. 장소별 JSON과 보충 Markdown은 runtime `data/gyms/`에 보존한다.

## 중량 단위

- 체육관 장비의 `loadUnit`이 `lb`이면 프로그램은 `startingWeightLb`로 처방한다.
- lb 장비의 세트 기록은 원본 표시값을 `weightLb`에 저장하고 `weightKg`를 함께
  저장하지 않는다. kg 장비는 기존처럼 `weightKg`를 사용한다.
- 앱의 세트 입력 열과 이전 기록은 해당 장비의 원본 단위인 kg 또는 lb로 표시한다.
- 총볼륨, 주간 통계와 e1RM처럼 공통 비교가 필요한 계산에서만
  `1 lb = 0.45359237 kg`으로 환산한다.
- 단위가 확인되지 않은 머신은 임의로 환산하지 않고 현장에서 확인한 뒤
  장소별 장비 파일에 `loadUnit`을 기록한다.

## 계획 작성 형식

- `cue`는 운동 중 휴대폰으로 읽는 문장이다. 목표 느낌, 핵심 자세 한 가지,
  대체 기준 한 가지까지 1-2문장으로 쓴다. 세트·반복·RPE·중량 필드에 이미 있는
  숫자는 반복하지 않는다.
- `substitutions`는 3개 이하로 쓴다.
- `coachNotes`는 오늘 바뀐 것과 그 이유를 5줄 이내로 쓴다.
- `muscleGroup`은 복합 운동에는 큰 부위(하체·가슴·등·어깨)를, 고립 운동에는
  구체 부위(대퇴사두·햄스트링·둔근·이두·삼두)를 써서 부위별 직접 세트가
  보이게 한다.
- 매일 계획에는 리뷰 파일을 만들지 않는다. 리뷰 파일은 구조 변경, 주간 리뷰,
  월간 리뷰 때만 남긴다.

## 주간 리뷰

주 1회, 최근 7일을 직전 3주의 주당 평균과 비교한다.

- 계획 대비 완료 세트
- 근육군별 직접 세트
- 종목별 증량 진행과 정체 종목
- 세션 RPE, readiness, 통증 메모
- 세션 길이와 누락 운동

구조 변경 신호가 없으면 구조는 그대로 둔다.

## 월간 리뷰

블록이 끝날 때 최근 4-6주를 본다.

- 수행률과 중량·반복 진행
- 부위별 볼륨과 정체 부위
- 체중과 같은 조건 InBody의 추세
- 체육관 변경이나 장비 제약
- 프로그램이 생활 일정 안에서 지속 가능한지

이 결과로 다음 블록의 구조를 정하고 리뷰 파일에 남긴다.
