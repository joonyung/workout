# Codex 코칭 프로토콜

## 역할 분리

Workout OS는 실행기이자 기록기다. Codex는 코치 역할을 맡아 저장된 데이터와
제약을 읽고 당일 프로그램과 주기별 조정안을 파일로 만든다.

- PWA: 오늘 프로그램 표시, 세트별 중량·반복·RPE·완료 기록, 타이머,
  프로필·체육관·인바디 입력
- Codex: 운동 선택, 볼륨·강도·휴식 처방, 대체 운동, 주간·월간 리뷰
- 파일 데이터: 두 역할이 공유하는 단일 기준

브라우저 저장소는 운동 중 즉시 반응과 오프라인 대비용이다. 로컬 서버가
연결되어 있으면 같은 기록을 runtime `data/workouts`에도 저장한다. Codex는 다음
프로그램을 만들 때 브라우저가 아니라 이 파일을 읽는다.

## 근거 기반 기본값

2026년 ACSM 업데이트는 복잡한 기법보다 꾸준한 수행을 우선하고, 주요
근육군을 주 2회 이상 훈련하며, 근비대 목표에는 근육군당 주당 약 10세트
수준의 높은 볼륨을 출발점으로 제시한다. 머신과 프리웨이트의 우열이나
매 세트 실패 지점까지 가는 것은 평균적인 건강한 성인에게 필수 조건으로
보지 않는다.

이 프로젝트의 기본 운용값은 다음과 같다.

- 주요 근육군 주 2회 노출을 우선한다.
- 초기 주당 직접 세트는 최근 기록이 없으면 근육군당 약 8-12세트 범위에서
  시작하고, 실제 수행률과 회복 반응으로 조정한다.
- 대부분의 작업 세트는 RPE 7-9, 즉 대략 1-3 RIR 범위로 둔다.
- 실패 훈련은 필수가 아니며, 피로 대비 이득이 분명한 일부 안전한
  보조운동의 마지막 세트에만 제한적으로 고려한다.
- 중량 증가는 반복 범위 상단을 목표 RPE 이내로 달성했을 때만 제안한다.
- InBody는 수분과 측정 조건의 영향을 받으므로 단일 측정값보다 여러
  측정의 방향성을 사용한다.
- 워밍업 세트도 필요하면 기록하되 작업 세트 볼륨, 수행률, e1RM 계산에서는
  제외한다. 다음 프로그램의 중량 기준은 작업 세트만 사용한다.

## 당일 프로그램 생성 절차

사용자가 "오늘 운동 만들어줘"라고 요청하면 Codex는 다음 순서로 진행한다.

1. npm run coach:context로 최신 컨텍스트를 확인한다.
2. runtime `data/profile.json`에서 목표, 운동 가능 일수, 시간, 통증·부상 메모를 읽는다.
3. runtime `data/gyms/current.json`에서 available 또는 limited 장비와 메모를 읽는다.
4. 최근 2-6주 운동의 수행률, 운동별 반복·중량·RPE, 부위별 세트, 세션 RPE를
   확인한다.
5. 최신 InBody는 장기 방향성 확인에만 사용하고 일일 중량 처방의 직접
   입력값으로 사용하지 않는다.
6. 오늘 날짜의 프로그램을 runtime `data/plans/YYYY-MM-DD.json`에 쓰고 같은 내용을
   runtime `data/plans/current.json`에도 반영한다.
7. npm run validate:data와 npm test를 실행한다.

장비 상태가 unknown이면 해당 장비를 필수 전제로 삼지 않고 대체 운동을
함께 넣는다. 부상·통증 메모가 비어 있거나 새 통증이 보고되면 고강도
처방을 확정하기 전에 사용자에게 확인한다.

운동 장소가 바뀌면 runtime `data/gyms/current.json`을 해당 장소 프로필로 전환한다.
장소별 JSON과 보충 Markdown은 runtime `data/gyms/`에 보존하며, 서로 다른 머신과
케이블의 표시 중량은 같은 운동 이름이어도 별도 기준선으로 취급한다.

## 세트 진행 규칙

동일 운동의 다음 처방은 최근의 유효 세트를 기준으로 한다.

- 모든 작업 세트가 반복 범위 상단에 도달하고 목표 RPE 이하:
  다음 세션에 가능한 최소 중량 단위만큼 증가
- 반복 범위 안이지만 목표 RPE를 1 초과:
  중량 유지, 반복수 안정화
- 두 세트 이상 반복 범위 하단 미달 또는 RPE 9.5 이상:
  다음 세션 2.5-7.5% 감량 또는 세트 1개 감소 검토
- 2회 연속 같은 운동 정체, 수행률 85% 이상, 회복 양호:
  운동 순서·반복 범위·운동 변형 중 하나만 변경
- 수행률 85% 미만:
  볼륨 추가보다 일정, 세션 길이, 운동 수를 먼저 줄임

운동마다 다른 머신의 숫자는 절대적인 비교가 어렵다. 체육관이나 머신이
바뀌면 새 기준선을 만들고 이전 수치와 직접 이어 붙이지 않는다.

## 주간 리뷰

주 1회 리뷰는 최근 7일과 직전 3주를 함께 본다.

- 계획한 세트 대비 완료 세트
- 근육군별 직접 세트
- 주요 운동의 e1RM 또는 동일 중량 반복수 추세
- 평균 RPE와 세션 RPE
- 피곤 상태 비율과 통증·메모
- 세션 길이와 누락 운동

한 번에 볼륨, 빈도, 운동 선택, 강도를 모두 바꾸지 않는다. 가장 가능성 높은
원인 하나를 선택해 다음 주에 검증한다.

## 월간 리뷰

월 1회는 최근 4-6주를 본다.

- 수행률과 중량·반복 진행
- 부위별 볼륨과 정체 부위
- 체중과 InBody의 여러 측정 추세
- 체육관 변경이나 장비 제약
- 프로그램이 생활 일정 안에서 지속 가능한지

2-4주 연속 성과 저하와 피로 신호가 함께 있으면 1주 동안 세트 수를
약 30-50% 낮추는 디로드를 후보로 검토한다. 통증, 어지럼증, 흉통 등
의학적 평가가 필요한 신호는 프로그램 자동 조정 범위를 벗어난다.
